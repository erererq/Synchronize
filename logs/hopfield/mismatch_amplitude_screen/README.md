# 参数失配基础幅度探索测试

本次比较基础幅度 0.03 与 0.05，分别取 eta=1 和 eta=2。相对失配范围依次为 ±3%、±5%、±6%、±10%。仅评估已有控制器，不重新训练、不重新调参，不替换论文原失配结果。

## 测试方法

- 节点：Node 2、Node 3。
- PPO/SAC：训练种子 42、123、1024 的全部最终模型，沿用论文检查点；模型 SHA256 记录在逐轨迹文件中。
- 传统控制：固定增益 k=8；LQR R=1 和已选定 R=0.01，均 Q=I；SMC reaching gain=16、boundary width=0.5。
- 每个模型/控制器、每个条件均使用测试种子 100–119，400 次采样保持更新、每次 5 个 RK4 子步，物理输入限幅 ±4。
- 两个幅度、所有方法共用相同初值与失配方向；通过 eta_effective=eta*amplitude/0.03 调用原环境，逐轨迹验证其失配矩阵与直接采样对应幅度一致。
- 合计 1600 条轨迹；所有 RK4 子步的状态截断触发次数为零。
- 指标调用 hopfield_revision_metrics.py：MAE 包含初始误差，控制代价为输入平方的时间积分。先对测试初值求均值，再对训练种子求均值。mae_seed_sd 是训练种子均值间的样本标准差；确定性基线该列留空。

## 结果解释

eta=2 时，幅度由 0.03 增至 0.05：

| 方法 | Node 2 MAE：0.03 → 0.05 | Node 3 MAE：0.03 → 0.05 |
|---|---|---|
| PPO | 0.170259 → 0.241065 | 0.065589 → 0.087221 |
| SAC | 0.151345 → 0.194796 | 0.064414 → 0.085962 |
| LQR R=1 | 0.232982 → 0.331714 | 0.098909 → 0.136669 |
| LQR R=0.01 | 0.148592 → 0.202670 | 0.064726 → 0.086836 |
| SMC | 0.222349 → 0.304605 | 0.125671 → 0.172548 |
| 固定增益 k=8 | 2.748066 → 2.736664 | 0.078509 → 0.106024 |

Node 2 的 PPO 仍优于参考 LQR R=1 和 SMC，但没有超过 LQR R=0.01。SAC 在更大失配下的均值略低于已调权重 LQR，同时控制代价较低；这只是当前测试集的均值关系，不是统计显著性结论。Node 3 的 PPO、SAC 和已调权重 LQR 误差接近，PPO 控制代价较高。

在 0.05、eta=2 的 Node 2 条件下，PPO、SAC、LQR R=0.01 的控制代价分别为 13.3934、10.0922、16.0113；Node 3 分别为 6.7749、5.4041、5.6144。完整 eta=1/2 指标见 summary.csv，逐轨迹数据见 episodes.csv。

加大失配并没有带来 PPO 相对所有方法的优势。若后续将更大幅度纳入正文，应以扩大鲁棒性测试范围为理由，同时保留原范围和全部方法；目前结果属于探索性测试。
