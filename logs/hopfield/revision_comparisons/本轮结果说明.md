# 优先级一、二的完成内容

## 传统基线

对2160条去重后的历史传统基线记录进行了重新仿真，逐条核对MAE、RMSE、稳态L1、末端L1、能耗、饱和率与脉冲恢复误差，差异均为0。固定增益仍为k=8。LQR的两个增益通过Riccati方程残差检查，SMC的参数选择用原10个验证种子得到复现。

正文现在说明了各方法需要什么观测、是否使用模型、SMC如何调参、实际脉冲加在哪里、噪声是哪一种，以及误差与能耗如何统计。状态保护边界在本轮全部2940回合中没有触发。

此外，旧节点比较和部分观测脚本把平均L1误差也标作MAE，与传统基线的分量MAE相差一个维度因子。本轮更新了节点汇总表；部分观测数据限制到共同的3个训练种子、原有10个测试初值，并将L1平均值除以3，图中的波动范围也改为正确的训练种子统计。原始数据未覆盖。

## SAC正式对照

SAC的Node 2、Node 3各从头训练3个种子（42、123、1024），每个401408步，与原PPO模型内部实际步数一致；每个模型测试20个初值。没有使用原10万步筛选模型，没有根据测试结果筛选种子。

| 测试 | PPO | SAC | 解读 |
|---|---:|---:|---|
| Node 2 标准条件MAE | 0.0930 | 0.1173 | PPO误差更低，但能耗更高 |
| Node 2 eta=2 MAE | 0.1703 | 0.1513 | SAC误差、能耗都更低 |
| Node 2 脉冲恢复平均L1 | 2.0800 | 1.9226 | SAC均值更低，但种子间波动与能耗更高 |
| Node 2 sigma=.05 MAE | 0.2669 | 0.2632 | 误差接近，SAC平均能耗更低 |
| Node 3 脉冲恢复平均L1 | 1.2969 | 1.3987 | PPO误差更低，但平均能耗更高 |

Node 3其余三个场景中SAC的MAE略低，且四个场景的平均能耗均较低。结论应是算法、场景和评价目标相关的取舍，不能再沿用10万步筛选时的“PPO优于SAC”判断。误差条是3个训练种子均值之间的标准差，不是60次独立训练的置信区间。

## 多输入PPO

全部7种非空组合均包含3个最终模型，总计21个；本轮补训练其中缺少的8个模型。每个模型预算401408步，标准条件测试20个共同初值。能耗对所有执行器求和。

| 配置 | MAE | 总能耗 |
|---|---:|---:|
| {1} | 1.3937 | 266.49 |
| {2} | 0.0930 | 9.09 |
| {3} | 0.0431 | 6.54 |
| {1,2} | 0.1145 | 20.61 |
| {1,3} | 0.0232 | 10.93 |
| {2,3} | 0.0205 | 8.15 |
| {1,2,3} | 0.0118 | 10.91 |

单控Node 3保留了较小残余误差，执行器更少，当前测得总能耗也更低；代价是全程平均误差高于较好的多输入组合。多输入并非稳态精度也全面更好。{1,2}在固定训练预算下表现不如{2}，该结果已保留；它不能证明增加执行器在理论上会降低可控性。
