## 先记住这三句话

- 稳定或平均误差小，不等于离散规则完全相同。
- 这次证明的是“满足明确条件，就一定能一致并恢复”，不是“PPO一定满足条件”。
- 测试检验现有策略在这些样本上是否满足条件；正确恢复不等于密码安全。

## 1. 为什么平均误差小还不够

例如 0.49 与 0.51，只差 0.02，却在取整边界两侧。直接量化得到0、1，两端选了不同规则。图像处理往往要求规则逐项相同，不能用平均意义上的接近代替。

原来的15轮滤波可能把规则压成常数，而且串联DNA映射有抵消问题。成功恢复的旧示例不能自动说明同步发挥了作用。因此不能给旧算法强行补一个并不适用的定理；新证明与新原型必须独立标记。

## 2. 新方法如何跨过这一步

以格宽 Δ=1 为例，发送端 x=0.49：

- 发送端整数 k=floor(x+0.5)=0。
- 偏移 r=x-k=0.49，通过辅助信息给接收端。
- 接收端 y=0.51，计算 floor(y-r+0.5)=floor(0.52)=0。

关键恒等式是 y/Δ-r = k+(y-x)/Δ。只要 |y-x|/Δ<0.5，去掉中心偏移后就不会越过取整边界。发送的不是整数规则，但偏移与发送端数据有关，有通信和泄漏代价，不能说不需要通信或已经安全。

半格条件使用严格小于，边界等于0.5不能算入。浮点计算还需留出数值裕量。

## 3. 三维同步误差为什么要变成四流误差

真正输入图像规则生成器的是 h=(x1,x2,x3,x1*x2+x3)，不只是原来的三维状态。设 e=y-x，第四流差值为：

`y1*y2+y3-(x1*x2+x3) = y2*e1+x1*e2+e3`。

若 |x1|、|y2| 不超过 M，每个误差分量不超过 ε，那么第四流差值不超过 `(2M+1)*ε`。前三流不超过 ε。因此 `(2M+1)*ε < Δ/2` 是一个较保守的充分条件。

这就是状态有界性与应用的真实连接：有界性给出了有限的误差放大系数，但不负责证明 ε 很小。3.3 的负条件指数、多步采样衰减也没有证明全局或整个邻域的 ε 上界。当前是在有限收集窗口内直接检查四流最大误差，而不是拿 MAE 当最大误差。

脚本同时核对更紧的逐样本代数上界 `max(|e1|,|e2|,|e3|,|y2|*|e1|+|x1|*|e2|+|e3|)`，并计入第四流单精度计算相对实数代数值的偏差。它验证上界传播代码没有漏掉第四流。没有给出整个浮点实现的形式化舍入误差证明。

## 4. 相同规则为什么保证恢复

每个字节分成四组两比特，各组用自己的规则进行可逆排列。相同规则下，接收端逆排列可以撤销发送端排列。剩余 XOR 掩码再 XOR 一次就还原，因为 `(a XOR q) XOR q = a`。

前提包括：同一密码及掩码生成信息、相同样本顺序和块顺序、未被篡改的辅助信息、相同数值实现。不满足这些前提，定理不保证恢复。实现中另有规则摘要检查，但摘要不是命题成立的原因。

八个规则采用字典序前八个四符号无不动点排列，各自作用在不同两比特位置，不再在同一位置串联而相互抵消。穷举4096种组合、每组256字节，均可逆。不同规则并不保证每个具体字节都变化，因此仍直接测试整图，不能仅凭规则不同宣称图像必坏。

## 5. 本次实验到底说明什么

标准参数、每0.05时间单位一次控制、幅值限制4、暂态1500步，收集256点，对同一128×128三通道天文图像按8×8分块。初值100/101/102，PPO训练种子42/123/1024。总36条独立配置轨迹，其中PPO18条、传统方法18条；同一初值的驱动轨迹按位一致。每条轨迹比较直接取整和偏移协调，两者用同一套新映射和同一掩码。

- PPO：Node 2最大四流误差0.126463，Node 3为0.036035，均小于固定阈值0.5。直接量化0/18整图完全恢复；协调后18/18完全恢复，规则不一致率及图像误差均为0。
- Node 2固定增益：3条都不满足条件，两种方式均0/3恢复。
- LQR、SMC两个节点以及Node 3固定增益：标准条件下存储状态已经逐点相同，两种方式全部恢复。这是浮点仿真的结果，不是有限时间同步定理。
- 不能因此说PPO胜过传统方法。实验回答的是“连续残余误差怎样经过离散处理影响恢复”，不是再次评选同步算法。
- 所有36条轨迹将接收规则替换为全1、主动绕过摘要检查后都不能完整恢复。这比仅看摘要拒绝更有助于排除规则完全不起作用的情况，但不是攻击安全评估。

所有名义轨迹没有触发状态保护。扩展的积分监控实现还与原环境在80步预设动作下进行了按位一致检查。合成边界测试中 ±0.49 成功、±0.51拒绝；+8依然通过，这是取模8的别名，故“超出阈值必然失败”是错误说法。充分条件只保证条件内成功。

## 6. 哪些问题还没解决

这不是已经可投稿的完整安全协议。辅助信息约20.7kB，约为本测试未压缩图像的42%，没有证明它不泄漏规则信息。未加密钥的SHA摘要不是认证，攻击者可同时改数据和摘要。还没有隐私放大、完整密钥管理、攻击分析。旧直方图和相关性图属于旧流程，不可当成新原型的安全测试。

因此正文分开写旧实现与新连接实验。后续必须与加密合作方决定最终统一哪套协议，再重新生成最终协议对应的图片和安全分析；本次未冒充已经完成这一步。
