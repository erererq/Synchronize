# Node 1传统控制器验证与实验表述精简

## 结论

现有 LQR 和 SMC 在 Node 1 的400步表现明显较差；延长测试后，部分 SMC 初值可以达到低误差，所以不能声称 Node 1不可同步，或传统方法必然失败。

本次是固定参数的名义条件诊断，不是 Node 1专门调参后的最优基线，也没有检查失配、脉冲或噪声。

## 设置与结果

每个节点、每种方法20个共同初值；三节点、两方法共120条轨迹。控制间隔0.05，幅值限制4。LQR使用Q=I、R=1；SMC沿用增益16、边界层0.5。未重新训练、未调整参数。

同一轨迹查看前400步和完整2000步，不是两组独立实验。MAE按三个误差分量、整个对应时间窗口平均，包含初值。末段为最后20%的采样。

| 节点 | 方法 | 400步MAE | 400步末段平均L1 | 400步控制能量 | 2000步末段平均L1 |
|---|---|---:|---:|---:|---:|
| 1 | LQR | 1.2893 | 3.2846 | 53.925 | 2.7482 |
| 1 | SMC | 1.2329 | 2.7518 | 82.162 | 0.4643 |
| 2 | LQR | 0.0907 | 2.02e-7 | 3.776 | 0 |
| 2 | SMC | 0.1018 | 3.63e-6 | 5.592 | 0 |
| 3 | LQR | 0.0510 | 2.24e-5 | 2.649 | 0 |
| 3 | SMC | 0.0728 | 5.03e-5 | 4.595 | 0 |

将“末段所有采样L1误差均小于0.01”作为本次诊断标准：

- 400步：Node 1两方法均0/20；Node 2、3两方法均20/20。
- 2000步：Node 1 LQR为0/20、SMC为5/20；Node 2、3两方法均20/20。

这是便于读数的阈值，不是新稳定性定义或证明。零表示存储的浮点误差为零，不是理论有限时间同步。所有轨迹均未触发状态保护。

Node 1的困难与原局部Riccati代价、反馈增益和控制传播指标的筛选方向一致，但该实验不能证明因果机制。尤其不能仅凭动作饱和比例解释全部失败，也不能推出任何其他参数、其他控制器都失败。SMC参数原先不是针对Node 1优化的，应明确这一限制。

## 是否还要DDPG

现有审稿意见要求增强传统控制基线与多输入比较，并未点名DDPG。已有固定增益、LQR、SMC、SAC和多输入消融，没有必要仅为增加算法数量继续堆DDPG。当前优先处理比较公平性、贡献表述与最终加密协议一致性。如果将来要宣称对多种DRL方法普遍占优，或新审稿人明确要求更多算法，再扩展。当前SAC比较只能支持已测试两算法的条件性结论，不能证明PPO最优。
