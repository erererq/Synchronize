核对了全部正式模型的文件哈希、训练步数、训练种子、观测/动作维度和主要超参数；240 条记录没有重复或缺失，数值均有限，没有状态保护触发。每个模型抽取一个共同初值重新运行，12 条重放轨迹的 MAE、尾段 L1 误差与能量均与归档值完全一致。

## 最重要的结果

O12 表示观测 x1、x2、e1、e2；O13、O23 同理。所有观测都按原环境除以 5。

| 配置变化 | PPO 的 MAE | SAC 的 MAE | SAC 的平均控制能量 |
|---|---:|---:|---:|
| Node 2：O12 → O23 | 0.9104 → 0.0866 | 0.4637 → 0.1350 | 40.73 → 7.17 |
| Node 3：O13 → O23 | 0.0438 → 0.0771 | 0.0562 → 0.0840 | 7.54 → 10.57 |

每个节点中，三个 SAC 训练轮次的误差变化方向都与上述均值方向一致。PPO 数据直接复用同一批测试初值上的已有结果，没有把旧的 10 初值统计混进来。

## 对创新点有什么帮助

这里核验的是“更换观测组合后误差如何变化”，不是一定要 PPO 战胜 SAC。

结果说明：在所测试的两个节点和两个组合之间，Node 2 更适合 O23，Node 3 更适合 O13 的误差排序不只在 PPO 上出现，SAC 也出现。这加强了现有发现的可信度，降低了“只是 PPO 某次训练偶然失败”的疑问。

但是，不能说已经证明算法无关性：只比较了两种算法、一个网络、每组三个训练轮次，而且 SAC 没有覆盖第三种四维组合。不能据此宣称最小观测要求、最佳传感器配置或正式稳定性。

## 能耗必须分开讲

Node 2 换组合后，SAC 能量下降；PPO 平均能量则基本不变。Node 3 换组合后，两者能量都上升，但 PPO 的增幅和轮次差异远大于 SAC。因此“误差排序方向得到复现”不等于“误差和能耗的全部规律均相同”。

也不能说每种四维配置下 PPO 都比 SAC 好：例如 Node 2/O12 的 SAC 误差更低。原文按场景讨论误差—能耗权衡的结论继续保留。
