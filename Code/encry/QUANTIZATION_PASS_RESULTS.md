# 反复滤波量化是否有用：实验与修改决定

## 结论

15轮不能简单说成“没有用”：它提高了本次样本的规则一致性和图像精确恢复率。但它同时把每条规则流压成常数，使同步信息的时序变化消失；许多样本不使用响应端规则也能恢复。它不适合作为“PPO同步驱动有效加密”的充分依据。

删除滤波也不能直接得到可靠的加密方案。直接量化暴露了边界附近的离散不一致；128×128图像在本次测试中均未精确恢复。我们不以提高成功率为唯一优化目标，也没有把这种失败隐藏起来。

## 测试条件

- Node 2、Node 3，各3个已训练PPO模型：训练种子42、123、1024。
- 每个模型使用初值种子100、101、102；每节点9条轨迹，总18条。
- 名义参数，CPU确定性预测，暂态1500步；每条轨迹再取256点。
- 图像为固定随机种子的8位三通道合成图，尺寸64×64与128×128，块边长8，分别用64和256个规则索引。
- 每条轨迹分别比较0、1、3、5、15轮；两种尺寸共享轨迹前缀，不是独立重复。总180个图像变换测试，不是180个独立训练试验。
- 所有条件共用相应原始轨迹，不重试、不筛失败；使用相同实验密码。
- 没有参数失配、扰动或真实图像大规模安全评估。

## 为什么不因此保留15轮作为默认

15轮下，所有节点/尺寸组合中：

- 主从规则完全一致，图像均恢复；但主、从每条规则流都只剩一个取值（细项结果可核对 rows）。
- 每个节点/尺寸的9个样本中，有6个把接收端4条规则全部替换成固定全1，仍然精确恢复。
- 相应主端两轮DNA复合映射有约2/3的块为恒等变换；这不是说整个密文变成明文，Logistic异或掩码仍在起作用。

对于128×128图像，主端常数流比例随轮数0、1、3、5、15分别为0%、0%、16.7%、58.3%、100%（两个节点相同；驱动轨迹不受响应端控制）。这说明恢复率改善伴随着严重退化。常数规则仍可能依赖轨迹，但已不再随块变化，不能据此证明同步不可替代。

固定全1实验仍保留相同密码和掩码，只测试响应端规则能否被替换，不是完整密码攻击或无密钥解密。

## 脚本修改

`photo_encry_checked.py`：

1. 新增 `quantize_streams(streams, filter_passes=0)`，默认仅执行一次 round/mod8映射，不再暗中循环15轮。
2. `--filter-passes` 显式选择0到15轮；`legacy_quantize`仍保留作历史回归。
3. 报告写入实际轮数、量化模式，继续输出恢复失败与退化指标。
4. 新增 `fixed_rule_exact_recovery`，记录固定全1接收规则是否也能恢复，并输出警告。
5. 保留原始 `photo_encry`，没有覆盖旧代码；没有改动论文及旧图片。论文此前对齐的是旧15轮实现，未来若采用新流程，必须重新对应方法和结果，不能混用。

**默认0轮是可解释的诊断基线，不是已经验证优于15轮的可靠加密方法。** 当前证据不支持直接选择某个轮数当成最终方案。下一步需要设计并验证离散一致性机制，同时处理DNA映射抵消；不能为了让指标好看，把错误序列都平滑成常数。
