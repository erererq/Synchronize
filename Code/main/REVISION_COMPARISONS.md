# 本轮对照实验的入口与统计口径

本轮只研究三阶 Hopfield 同步控制。原模型、旧实验 CSV 和加密代码均保留。

## 运行环境与入口

在项目根目录使用 `E:\Users\anaconda3\envs\lea\python.exe`。

1. `Code/main/train_hopfield_revision.py --all --workers 6`：补训练缺少的 SAC 与多输入 PPO 最终模型。已完成的新模型会按步数和种子核验后跳过。
2. `Code/main/evaluate_hopfield_revision.py --require-complete --workers 3`：全部训练完成后评估。`--available` 可先评估已经存在的模型。每个任务的 CSV 只有完整完成后才写入，重新运行可复用已完成评估。
3. `Code/main/audit_hopfield_revision.py`：核对单输入/多输入环境等价性、Riccati 残差、指标计算和历史 SMC 验证参数。
4. `Code/main/refresh_hopfield_legacy_reporting.py`：修正旧节点和观测实验的 L1/MAE 混用，重建对应图表。
5. `Code/main/report_hopfield_revision.py`：检查结果完整性、复现旧基线数据，再生成 SAC 和多输入图表。`--traditional-only` 可在训练尚未完成时只核对传统基线。

输出目录为 `logs/hopfield/revision_comparisons`。其中 `evaluation` 保存逐模型、逐初值、逐场景记录，`raw_metrics.csv` 是统一汇总，`per_seed_metrics.csv` 先对每个策略的20个初值取均值，`metrics_summary.csv` 再汇总训练种子。论文自动生成表格在 `Manuscript/generated`，新模型在 `models/hopfield/revision_comparisons`。

不要同时启动两个相同训练任务或两个相同评估任务。每个文件对应固定算法、节点配置和训练种子；更改协议或脚本计算逻辑后，应使用新的输出目录，不能直接沿用缓存。

## 第一优先级：传统基线

- 固定增益始终为 k=8，不重新调参。
- LQR 使用原点局部模型 A=W-I，Q=I，R=1。实际输入是限幅后的 -Ke，不能把局部 LQR 最优性解释为饱和非线性系统的全局最优性。
- SMC 用完整驱动/响应状态和名义非线性补偿。k_s=16、phi=0.5；历史验证集为种子0--9，包含标准条件、eta=1和脉冲。参数选择并非只接触标准条件。
- PPO 训练只接触标准条件。执行时输入为6维观测 (x,e)/5；LQR 为3维误差；SMC需要等价于6维的状态信息；固定增益只需要被控制节点误差。
- 所有方法均400次更新，每次0.05，总时长20；物理动作限幅4。
- 同一场景共享测试种子100--119、初值和扰动随机实现。失配非零时环境先抽失配矩阵，所以 eta=0 与 eta>0 即使种子相同也不是逐个相同初值；不能把跨场景变化当作严格配对效应。
- 脉冲在第200步积分后加到驱动系统三个状态，向量(5,5,5)。这是参考轨迹突变后的恢复测试。
- 高斯噪声加到响应状态，是过程噪声，不是仅污染传感器读数的测量噪声。

## 第二优先级：SAC 与执行器数量

- PPO 文件内部实际步数为401408（原设置40万，最终补满一次rollout）。新 SAC 严格训练401408步，从头训练，种子42、123、1024，保存最终模型；不使用旧10万步筛选模型作为正式对照。
- SAC 保留筛选时的算法参数，3个种子、2个单输入节点，测试标准条件、eta=2、脉冲、sigma=0.05。相同交互预算不等于相同优化次数或训练时间，也不代表已经穷尽SAC调参。
- 多输入只做标准条件同步，涵盖全部七种非空节点组合，每组3个最终模型。复用已核验的单输入模型和多输入seed42；其余8个重新训练。
- 每个执行器都限制在[-4,4]。多输入拥有更多作用方向和更大的总控制幅值预算，不能说成同总控制能力比较。
- 能耗对所有执行器求平方和再时间积分。单输入只能直接说明执行器数量少；是否省能耗由结果决定。

## 指标与误差条

误差数组包含初始值，共401个时刻；动作数组初始补零，实际400次控制。MAE对时间和3个误差分量同时取平均，等于时间平均L1误差除以3。RMSE直接从误差分量平方计算，不是L1范数的均方根。

稳态L1取第320--400个采样值，共81个，区别于最终时刻L1。脉冲恢复平均L1取第200--400个值，共201个。能耗为0.05乘以所有400步、所有执行器实际限幅动作的平方和。

SAC/多输入表格中的标准差来自3个“每策略20个初值均值”，不能把60条轨迹当作60次独立训练。传统控制器没有训练随机种子；其初值离散度与学习方法的训练种子离散度应区别解释。

旧部分观测记录中2D/4D有5个训练种子，而6D仅3个。本轮展示统一截取共同的42、123、1024，以及原有的10个测试初值100--109，并从记录的L1误差除以3得到正确MAE。此项没有重新训练或改变原观测策略。

## 核验记录

`protocol_audit.json` 记录环境等价、Riccati和SMC参数检查；`result_audit.json` 记录对2160条非重复旧传统基线记录的逐条复现（旧sigma=0与标准条件重复，未重复计算）。新评估同时记录状态数值保护边界是否触发。

论文中的能耗取舍、场景依赖以及3个训练种子的限制应保留。不要把某一个实验平均值较低推广为算法全面优越，也不要按结果删去困难组合或表现不佳的种子。
